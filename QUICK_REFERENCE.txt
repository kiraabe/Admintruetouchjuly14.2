Category        Max Size    Allowed Types                Use Case
─────────────────────────────────────────────────────────────────────────────
candidates      10 MB       IMG, PDF, DOC, DOCX, TXT    Profiles, resumes

jobs            5 MB        IMG, PDF                    Job listings
documents       15 MB       PDF, DOC, DOCX, TXT         General docs
images          10 MB       IMG                         Image gallery


┌──────────────────────────────────────────────────────────────────────────────┐
│ ALL UTILITY METHODS                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

uploadFile(file, category)              → Upload single file
uploadFiles(files, category)            → Upload multiple files (max 10)
listFiles(category)                     → Get all files in category
getFileInfo(category, filename)         → Get file details
deleteFile(category, filename)          → Delete a file
getStats()                              → Get storage statistics
getFileUrl(category, filename)          → Generate public URL
downloadFile(url, filename)             → Download file to computer


┌──────────────────────────────────────────────────────────────────────────────┐
│ API ENDPOINTS (Backend)                                                      │
└──────────────────────────────────────────────────────────────────────────────┘

POST   /api/files/upload/:category              Upload single
POST   /api/files/upload-bulk/:category         Upload multiple
GET    /api/files/list/:category                List files
GET    /api/files/info/:category/:filename      Get file info
DELETE /api/files/delete/:category/:filename    Delete file
GET    /api/files/stats                         Storage stats
GET    /uploads/:category/:filename             Serve file (public)

Upload with state:
  const [url, setUrl] = useState('')
  const res = await fileServer.uploadFile(file, 'candidates')
  if (res.success) setUrl(res.file?.url || '')

Bulk upload:
  const res = await fileServer.uploadFiles(files, 'documents')
  res.files?.forEach(f => console.log(f.url))

Display list:
  const { files } = await fileServer.listFiles('candidates')
  return files.map(f => <img src={f.url} key={f.filename} />)

Download:

CORS error → Check server CORS settings
Slow uploads → File size too large
